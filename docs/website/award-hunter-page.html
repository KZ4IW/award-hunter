Never miss a needed state again.

award-hunter watches what WSJT-X decodes and colours the stations you still need for America250 WAS, Worked All States, grid squares and DXCC, right in WSJT-X's Band Activity window. A browser dashboard shows what's needed, which W1AW/n is on this week, and which band is open to the states you're missing.

What it does

🎯 Highlights in WSJT-X

Needed stations turn blue in Band Activity. Dark blue = LoTW user, light blue = not. Blue, because WSJT-X already uses magenta.

🇺🇸 America250 aware

Paste your credits from the award page. It knows which W1AW/n is on the air each week and stops highlighting a state as soon as you log it.

📡 Band tips

Uses PSK Reporter to show which band is bringing needed stations into your grid right now.

🔔 Alerts

Desktop notifications, plus optional phone push alerts through ntfy.

🖥️ Browser dashboard

Runs on the shack PC, or check it from a tablet over remote desktop.

🤝 Works with GridTracker

Both programs listen to WSJT-X's multicast UDP feed at the same time, with no relay setup.

A closer look

Get it

Source code and full install instructions are on GitHub: github.com/KZ4IW/award-hunter

$ sudo apt install pipx
$ git clone https://github.com/KZ4IW/award-hunter.git
$ cd award-hunter && pipx install .
$ award-hunter init
$ award-hunter run

Then set WSJT-X's UDP Server to 239.255.0.1 port 2237, tick the loopback interface, and open http://127.0.0.1:8073 in a browser on the same computer.
