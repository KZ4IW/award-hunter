award-hunter

Designed by KZ4IW · Free and open source (GPL-3.0) · Linux

award-hunter watches what WSJT-X decodes and points out stations you still need for an award, right in WSJT-X's Band Activity window. It was built for the ARRL America250 WAS event in 2026 and also handles plain Worked All States, grid squares and DXCC.

What it does

  • Colours needed stations in WSJT-X. Dark blue means the station uploads to LoTW, so your contact will probably confirm. Light blue means it doesn't. Blue is used because WSJT-X already uses magenta for its own colouring.
  • America250 aware. Paste your credits from the award page and it works out which states you still need. It knows which W1AW/n station is on the air each week, and it stops highlighting a state as soon as you log it.
  • Band tips from PSK Reporter. A per-band table shows which band is bringing needed stations into your grid right now.
  • Alerts. Desktop notifications, plus optional phone push alerts through ntfy.
  • Browser dashboard. Works on the shack PC, or from a tablet over remote desktop.
  • Plays nicely with GridTracker. Both programs listen to WSJT-X's multicast UDP feed at the same time, with no relay setup.

Get it

Source code and install instructions: TODO repository link

pipx install .
award-hunter init
award-hunter run

Then set WSJT-X's UDP Server to 239.255.0.1 port 2237, tick the loopback interface, and open http://127.0.0.1:8073 on the same computer.
